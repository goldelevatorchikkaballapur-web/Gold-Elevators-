# Gold Elevators Website

A responsive static website for Gold Elevators.

## Files
- `index.html` - website content
- `style.css` - design and responsive layout
- `script.js` - mobile menu and current year
- `logo.jpg` - supplied Gold Elevators logo

## Publish on GitHub Pages

1. Create/sign in to your GitHub account.
2. Create a new **public repository**, for example `gold-elevators-website`.
3. Upload all four files/folders from this project to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main** and folder **/ (root)**, then click **Save**.
7. GitHub will provide your website address, usually:
   `https://YOUR-USERNAME.github.io/gold-elevators-website/`

The WhatsApp, phone, email and Google Maps buttons are already configured with the details supplied.
