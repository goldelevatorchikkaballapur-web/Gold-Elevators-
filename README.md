# Gold Elevators Website

A responsive, static website for **Gold Elevators**.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload **all files and folders** from this project.
3. In GitHub, open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select your main branch and `/ (root)`, then Save.
6. GitHub will provide the live website address.

## Included

- Responsive premium gold/black design
- Uploaded Gold Elevators logo
- Visible golden elevator background
- Click-to-call phone number
- Email link
- WhatsApp button
- Google Maps links for all listed locations
- Services and service areas
- Mobile navigation
